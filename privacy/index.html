Privacy

プライバシー

この公開ページは、LPの要件、作業フォルダ、作業ファイルを運営者へ送信しません。独自のアクセス解析も接続していません。

GitHub Pagesで配信しています。

GitHub Pagesでは、セキュリティ目的で訪問者のIPアドレスが記録・保存されます。詳しくはGitHub Pagesのデータ収集説明とGitHubのプライバシーステートメントをご確認ください。

このページで扱うデータ

運営者側のanalytics providerは接続していません。JavaScriptは、ページ表示、個別ファイルのdownload／copy、ZIP download、ヘルプ遷移の最小イベントをブラウザのメモリ上の一時キューと CustomEvent に記録します。

イベントはネットワークへ送信せず、ページを閉じると保持されません。Cookie、localStorage、sessionStorageは使用していません。

収集・送信しない情報

  • LPのテーマ、対象者、CTA、価格、proof等の対話内容
  • 作業フォルダのパス、ソースコード、実装結果
  • clipboardへコピーしたMarkdown本文
  • Codexでの会話
  • 氏名、メール、電話番号、LINE UID等の識別情報
  • APIキー、パスワード、秘密情報

downloadとコピー

2つのMarkdownとZIPはこの公開ページと同じoriginから配信します。コピー操作は同じoriginのMarkdownを読み込み、ブラウザのClipboard APIまたは画面内fallbackを使います。本文を運営者の外部サービスへ送信しません。

Codex側の扱い

Codex環境、接続サービス、作業フォルダには、利用者自身の設定と各サービスの規約が適用されます。顧客個人情報、APIキー、パスワード、未共有の秘密情報を依頼文へ含めないでください。

問い合わせ

このページに関する問い合わせは X @itagent_oss へお願いします。公開ページへ入力フォームは設置していません。
