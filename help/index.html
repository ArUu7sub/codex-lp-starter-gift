受取ヘルプ

2つのMarkdownの取得、コピー、送る順番を確認できます。Skillの設置は必要ありません。

受取と利用に、ローカルサーバー起動は不要です。

この公開ページから2つのMarkdownを受け取り、Codexへ順番に送ってください。LPのpreviewもCodexが起動・確認します。

1. ファイルをダウンロードできない

  1. トップページの「2つの制作ファイル」へ戻ります。
  2. セットアップ.md と lp実装.md の個別リンクを試します。
  3. ブラウザのダウンロード制限と保存先を確認します。
  4. ZIPが取得できない場合も、2つの個別ファイルだけで利用できます。

JavaScriptが無効でも個別ファイルとZIPのdownloadリンクは使用できます。

2. コピーボタンが動かない

個別ファイルをダウンロードするか、リンク先でMarkdownを開き、全文を手動でコピーしてください。スマートフォンでは長押し、PCではCtrl+C（macOSはCommand+C）を使えます。

3. どちらを先に送るか分からない

  1. CodexへLP用の作業フォルダを指定します。
  2. セットアップ.md を送ります。
  3. assistantの応答に、作業フォルダの絶対パスと [LP_STARTER_STATE: SETUP_READY] があることを確認します。
  4. lp実装.md を送ります。

2つを同時に送らず、準備完了の応答を間に挟んでください。

4. セットアップで止まった

作業フォルダが不明、存在しない、複数候補がある、アクセスできない場合、Codexは作業フォルダについて1問だけ確認します。正しい絶対パスを答えてください。推測でフォルダを作らせないでください。

5. LP実装が開始されない

直前のassistant応答に絶対パスと状態マーカーがない場合、lp実装は開始されません。現在のメッセージへ状態マーカーを書き足すのではなく、セットアップからやり直してください。

6. 対話で答えが未定の場合

「なし」「未定」も有効な回答です。色や余白のような可逆的な選好にはCodexが推奨案を出せますが、価格、実績、資格、口コミ、期限、法的事項は推測しません。Primary audienceとPrimary CTAは実装前に決めます。

7. ZIPの完全性を確認したい

version 2.0.2のZIPは 21274 bytes です。期待するSHA-256は次の値です。

315e9b19e44377c10054299d215b288b1a7d061776b800fc0894f0639be368e1 sha256sum codex-lp-starter-v2.0.2.zip
